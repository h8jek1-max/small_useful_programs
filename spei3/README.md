
SPEI3 (Standardized Precipitation Evapotranspiration Index): This is a drought index calculated in 3 months. It takes into account not only precipitation, but also the evaporative (evapotranspiration) affected by temperature. The three-month window is crucial in agriculture because it shows excellent soil moisture and incipient agricultural drought.
 genlogistic: The index was fitted using a generalized logistic statistical distribution (common scientific procedure for SPEI). 
 era5_moda: Data comes from the ERA5 reanalysis (peak historical weather model from ECMWF) and is a monthly average (moda).
     The file contains data 1990 - 2026.
       Values such as 0.498249, 0.523451, etc. are standardized values of the SPEI index.
 These usually range from -3 to +3: 0: Absolute normal for a given place and month.
      Positive values (e.g. your ~0.5): A slightly wetter period than the long-term average.
           Negative values (e.g. below -1): Oncoming drought.
            The values below -2 mean extreme drought.

    SPEI3 (Standardized Precipitation Evapotranspiration Index): Jedná se o index sucha počítaný za 3 měsíce. Zohledňuje nejen srážky, ale také výpar (evapotranspiraci) ovlivněný teplotou. Tříměsíční okno je v zemědělství klíčové, protože skvěle ukazuje půdní vlhkost a počínající zemědělské sucho.
    genlogistic: Index byl napasován pomocí zobecněného logistického statistického rozdělení (běžný vědecký postup pro SPEI).
    era5_moda: Data pocházejí z reanalýzy ERA5 (špičkový historický model počasí od ECMWF) a jde o měsíční průměry (moda = monthly data).
    ref1991to2020: Jako referenční (klimatologické) období pro určení toho, co je „normál“, co je „sucho“ a co „nadprůměrné vlhko“, byla použita nejnovější standardní léta 1991 až 2020.
    Soubor obsahuje data 1990 - 2026.

Hodnoty jako 0.498249, 0.523451 atd. jsou standardizované hodnoty indexu SPEI. Ty se obvykle pohybují v rozmezí od -3 do +3:

    0: Absolutní normál pro dané místo a měsíc.
    Kladné hodnoty (např. vaše ~0.5): Mírně vlhčí období, než je dlouhodobý průměr.
    Záporné hodnoty (např. pod -1): Nastupující sucho. Hodnoty pod -2 znamenají extrémní sucho.
